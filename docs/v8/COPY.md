# Words GardenSync uses

One name for each thing, everywhere: interface, docs, assistant prompt. US English (D-A10). No em
dashes in anything a person reads.

| Say | Not | Meaning |
|---|---|---|
| garden | plot, project, plan | Everything one gardener keeps in one place. A browser can hold several. |
| bed | grid, box | A rectangle on the square grid: raised bed, in-ground bed, planter, window box, trough. |
| pot, grow bag, bucket, tower | vessel (in the interface) | Containers measured by soil volume. "Vessel" is a code word only. |
| bed or pot, beds and pots | containers (in the interface) | The plain-words umbrella when both kinds are meant. |
| square | cell, tile | One 1 ft or 30 cm square. Name squares like a map: A1 is the top-left. |
| planting | patch (in the interface) | One crop in one set of squares (or one pot), with its dates and count. |
| plant | crop, variety (as the umbrella) | Anything in the library. "Variety" only for a named kind of a plant, like Sungold. |
| your plants, custom plant | user plant | A plant or variety the gardener added. |
| sow, start indoors, plant out, plant | transplant (as a verb in tasks) | The four ways a planting goes in. "Bought plants" for nursery starts. |
| window | slot, range | The span of days a planting can go in. "Spring window", "fall window", "overwinter". |
| last frost, first frost | LF50, FF50 | Typical dates (the median of 30 years). |
| frost-safe from | LF90 | The date 9 years in 10 are past. Tender crops wait for it. |
| your climate | weather, location settings | Frost dates, zone and temperatures for the garden's town. |
| This week | tasks, to-do | The jobs due now. A job is "ticked" when done. |
| pick, harvest | yield (as a verb) | "Log a harvest", "picked so far". "Yield" only for the expected amount. |
| friends, foes | companions, antagonists | Pairs that help or hurt each other. Each says "trials back this" or "traditional". |
| assistant | AI, chatbot, Claude (as its name) | The optional helper. "Runs on Claude" when saying what powers it. |
| download a copy, open a saved copy | export, import | Saving the garden to a file and reading one back. |
| share a link | publish | A link that opens a copy of a garden. |

Dates on screen: "Apr 16" in running text, "Thursday, Apr 16" where the weekday helps, "Apr 16 to
May 2" for ranges. Never "4/16" or "16/4".

Numbers: lb and oz or g and kg; ft and in or m and cm; °F or °C. Round to what a gardener can act
on: "about 10 lb", "a 3 gallon pot", "12 in apart".
