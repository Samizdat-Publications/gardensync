What Is GardenSync?

GardenSync is an interactive, community-first garden bed planner designed for Food Not Bombs Canton, OH. Drag and drop plants onto 5x10 foot beds with real companion planting rules, AI-powered Garden Buddy chat assistant, harvest tracking, and season-aware scheduling for Zone 6a.

No corporate ag. No monoculture. Just honest gardening tools built for mutual aid, food sovereignty, and radical abundance. Open source. Free. Anarchist-coded.

FNB Research Gardens

Three research-backed demo gardens for Food Not Bombs Canton. Each plan optimizes for different goals: maximum yield, easy start for new gardeners, and year-round storage.

Greens Powerhouse

Kale, swiss chard, collard greens, lettuce, spinach, parsley. #1 food bank request — 3-season harvests from a single planting.

Tomato & Pepper HQ

Classic companion guild — tomatoes, peppers, basil, marigold, sweet alyssum. One plant yields 10-20 lbs.

Underground Vault

Onion, carrot, beet, chive. Root vegetables store 2-5 months without refrigeration — food bank storage backbone.

Calorie Central

24 potatoes — highest calorie crop per sqft. Stores 4-6 months. One bed yields 50-100 lbs for multiple families.

Storage & Protein

Butternut squash (3-6 month storage), green beans (plant protein), 7 cooking herbs for on-site meal prep.

Features

Drag & Drop

Click to place, drag to move, 20px grid snapping. Design your garden visually in minutes.

Companion Plants

41-plant library with real companion/enemy rules. See companion connection lines on canvas.

Garden Buddy AI

Claude Sonnet AI assistant with tool use. Ask questions, get plant advice, auto-arrange beds.

Zone 6a Ready

Canton, OH climate data. Frost dates, season calendars, and crop-specific growing timelines.

Cloud Sync

Local storage + Supabase cloud backup. Auto-saves every 5 minutes. Share gardens via URL.

Harvest Tracking

Log harvests, view yields, plan for next season. Build garden knowledge over time.

Tech Stack

Built with open tools. No corporate surveillance. No tracking. Just honest code.

Vanilla JS

No framework. No webpack. ~30 modular JS files. Fast and lightweight.

Canvas Rendering

Beds, plants, companion lines, and climate charts drawn on canvas. Smooth and performant.

Claude Sonnet 4

Garden Buddy AI with tool use. Real knowledge, real conversations about your garden.

Supabase

Open source PostgRES backend. Cloud sync, garden persistence, no AWS lock-in.

Open Meteo API

Free weather data. No API keys required. Privacy-respecting real-time forecasts.

Anarchist Code

MIT licensed. View source. Fork. Modify. Share. Food not bombs spirit in the code.
